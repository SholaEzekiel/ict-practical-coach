# ICT Theory Image Sourcing Manifest

Use this manifest to source stable, student-facing images for the ICT Theory lessons.

Recommended workflow:
- Source one unique image for every listed file path.
- Prefer Unsplash photos where the subject is clearly relevant.
- Use Wikimedia Commons or another open educational source only when Unsplash cannot show the topic clearly.
- Avoid abstract filler, repeated photos, and images that do not visibly match the lesson.
- Save each file locally in `public/assets/ict-theory/...` using the exact suggested filename.
- Use `.jpg` for photos and `.png` only for screenshots/diagrams where needed.
- Keep images landscape where possible, around `640x420` or larger.

Slot pattern:
- `01-concept.jpg`: broad visual for the lesson idea.
- `02-detail.jpg`: close-up or comparison subject.
- `03-real-world.jpg`: actual device, system, or workplace use.
- `04-context.jpg`: wider scenario or exam-style context.
